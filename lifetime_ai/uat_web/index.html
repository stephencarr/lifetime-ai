How to use this workbench

  1. Import a small, relevant source slice once.
  2. Ask a question in Retrieval lab and inspect its cited source.
  3. Correct a wrong or stale memory, then ask again to see whether the correction persists.
  4. Delete test memory that should no longer be retrieved. Tag failures when useful.
